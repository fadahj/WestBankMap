1967

Israel captures the West Bank, east Jerusalem and the Gaza Strip in the Mideast war. Settlement construction begins soon after.

Half a century of settlements

In 56 years, Israel has built well over 100 settlements scattered across the West Bank. Settlers have also built scores of unauthorized outposts, tolerated or even encouraged by the government.

Outposts multiply

From the late 1990s, small unauthorized outposts spread rapidly alongside official settlements — some later legalized retroactively.

Dwindling two-state prospects

With more than 500,000 Israeli settlers now living in the West Bank, partitioning the territory for a two-state solution grows more difficult.

Notes for recreation / animation

This is a functional reference build, not the final graphic — it demonstrates the interaction mechanics and carries the real data so the look can be rebuilt in whatever tool/engine is used for the final piece (After Effects, a custom WebGL build, etc).

Interaction: the map is pinned (position:sticky) while the page scrolls. Scroll progress (0–1) maps linearly to a year between 1967–2024. Points appear when their year property is ≤ the current year — see the updateYear() function in the page source. This mirrors the original AP graphic's approach (a MapLibre circle-opacity expression keyed to a scrubbed year).

Data: data/settlements.geojson — 426 points (163 settlements, 120 outposts, 120 farms, 14 industrial areas, 6 tourism sites, 2 other, 1 planned), each with name, name_he, type, year. 18 features (mostly industrial areas/councils) have no meaningful founding year in the source data and are always shown. data/green_line.geojson — the 1949 Armistice Line, for context.

Color key: settlements #CD3636 (red), outposts #00659D (blue). Other types shown in neutral gray #9AA0A6 so they don't compete visually but stay visible for reference.

Basemap: OpenFreeMap's "positron" vector style (free, no key, no rate limit), a stand-in for AP's ESRI/OSM basemap. Used as a vector style rather than flattened raster tiles specifically so labels can be filtered by admin level — the label_state layer (Jordan's governorates, Israeli/Palestinian districts) is hidden, leaving only country/territory-level place names. For a final production piece, swap the style: URL for a licensed/custom basemap.

Attribution requirement: the underlying settlement data belongs to Peace Now (an Israeli anti-settlement monitoring group) — any published version should credit "Data: Peace Now" as AP's original did.

Type & brand: verified against a live rendered News article on thenationalnews.com rather than trusting the site's generic CSS variables alone — those name Playfair Display as the "primary" font, but that face turns out to only be used for opinion pull-quotes; every actual News headline, standfirst and byline renders in Inter. So headline/year use Inter 800/900 (matching the site's real 48px/800 H1 treatment, scaled down for this panel), and standfirst-style caption text uses Inter 400 at #999 (matching the live standfirst color). Card shadows/radius use the site's own --box-shadow and --global-border-radius-1 tokens.
